# Contributing Guidelines

Thank you for considering contributing to the Simple Interest Calculator project!

## Welcome
All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute
1. Fork the repository.
2. Create a new branch for your feature or bug fix: `git checkout -b feature-name`.
3. Make your changes and commit them with clear messages.
4. Push your branch to GitHub: `git push origin feature-name`.
5. Open a Pull Request explaining your changes.

## Bug Reports
If you discover a bug, please open an issue detailing the steps to reproduce it along with your operating system or browser environment.
